Kitt# Kittr 🧰

**Curated no-signup web tools. Open in your browser. Done.**

Kittr adalah gudang tools online pilihan yang bisa langsung dipakai tanpa bikin akun, tanpa login, dan tanpa ribet. Cukup buka halaman, klik tool-nya, dan langsung kerja.

---

## 🔥 Kenapa Kittr ?

- ⚡ **Langsung pakai** – nggak ada halaman "Sign Up dulu ya"
- 🌐 **Semua di browser** – nggak perlu install aplikasi tambahan
- 🧠 **Dipilih manual** – bukan sekadar list acak, tiap tools dicek dulu kegunaannya
- 🆓 **Gratis & open source** – lisensi MIT, bebas dipakai dan dikembangin
